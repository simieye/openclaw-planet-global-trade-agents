# Memory 记忆系统 — Layer 3

## 四级记忆架构

### 1. 用户记忆 (User Memory)
- **个人信息**：用户画像、行为偏好、消费习惯
- **交互历史**：对话记录、服务请求、反馈评价
- **价值路径**：用户成长轨迹、价值贡献度
- **用户类型**：10 类用户自动识别（消费者/代理商/合伙人/加盟商/供应商/投资人/媒体/KOL/员工/访客）

### 2. 组织记忆 (Organization Memory)
- **企业历史**：发展里程碑、重大事件、关键决策
- **组织架构**：部门结构、人员配置、权责关系
- **项目记录**：项目全生命周期数据、经验教训
- **供应链**：供应商关系、物流网络、库存历史
- **合作关系**：合作伙伴、联盟成员、生态关系

### 3. 生态记忆 (Ecosystem Memory)
- **产业联盟**：OPC共生体系成员、资源匹配历史
- **全球节点**：城市运营中心数据、区域市场特征
- **知识沉淀**：行业最佳实践、SOP流程、培训资料
- **市场情报**：竞品数据、趋势分析、消费者洞察

### 4. 文明记忆 (Civilization Memory)
- **商业文明**：全球商业演进趋势、行业变革规律
- **技术演进**：AI技术发展里程碑、技术栈演变
- **文化基因**：跨文化商业智慧、全球化经验
- **知识继承**：跨代际、跨企业的知识传承

## 记忆技术架构

### 短期记忆
- **容量**：当前会话上下文（4096-8192 tokens）
- **用途**：实时对话、即时任务处理
- **更新频率**：实时

### 长期记忆
- **存储**：向量数据库 + 知识图谱
- **用途**：历史数据检索、模式识别、趋势分析
- **更新频率**：每日同步

### 共享记忆
- **范围**：跨Agent共享的企业知识库
- **用途**：协同决策、跨部门协作
- **同步机制**：实时广播 + 定期同步

### 记忆操作
- **写入**：任务完成时自动记录
- **读取**：决策时按相关性检索
- **遗忘**：过期/低价值信息自动衰减
- **继承**：新Agent自动继承相关记忆
