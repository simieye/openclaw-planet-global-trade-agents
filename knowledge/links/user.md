# User 用户理解 — Layer 4

## 10 类用户自动识别系统

### 1. 消费者 (Consumer)
- **特征**：浏览商品、加购、下单、复购
- **需求**：高性价比产品、优质服务、便捷体验
- **价值路径**：新客 → 活跃用户 → 忠诚会员 → 品牌大使
- **触达渠道**：独立站、Amazon、TikTok Shop、WhatsApp

### 2. 代理商 (Agent/Distributor)
- **特征**：寻找品牌代理、区域分销权
- **需求**：品牌授权、产品供应、营销支持、利润空间
- **价值路径**：咨询 → 评估 → 签约 → 首批进货 → 持续合作
- **触达渠道**：招商页面、行业展会、LinkedIn、邮件

### 3. 合伙人 (Partner)
- **特征**：寻找深度合作、资源互补
- **需求**：战略合作、资源共享、联合品牌
- **价值路径**：接洽 → 方案 → 谈判 → 签约 → 协同运营
- **触达渠道**：行业峰会、商务社交、推荐介绍

### 4. 加盟商 (Franchisee)
- **特征**：寻找加盟品牌、开店创业
- **需求**：品牌体系、运营手册、培训支持、供应链
- **价值路径**：了解 → 考察 → 申请 → 审核 → 签约 → 培训 → 开业
- **触达渠道**：招商会、线上说明会、Webinar、社群

### 5. 供应商 (Supplier)
- **特征**：提供产品或服务供应
- **需求**：稳定订单、长期合作、付款保障
- **价值路径**：资质审核 → 样品评估 → 小批量试单 → 长期合作
- **触达渠道**：1688、Alibaba、行业展会

### 6. 投资人 (Investor)
- **特征**：寻找投资机会、高增长项目
- **需求**：投资回报、项目信息、退出机制
- **价值路径**：初步了解 → 详细尽调 → 条款谈判 → 投资 → 投后管理
- **触达渠道**：路演、投资峰会、FA推荐

### 7. 媒体/KOL (Media/KOL)
- **特征**：寻找报道素材、合作机会
- **需求**：新闻素材、独家内容、合作费用
- **价值路径**：媒体关系建立 → 内容合作 → 传播放大
- **触达渠道**：媒体库、PR Agency、社交媒体

### 8. 员工 (Employee)
- **特征**：AI企业中的数字员工与人类员工
- **需求**：任务分配、技能提升、绩效反馈
- **价值路径**：入职 → 培训 → 成长 → 晋升
- **触达渠道**：Workspace OS、企业微信、飞书

### 9. 访客 (Visitor)
- **特征**：首次访问、信息浏览
- **需求**：了解企业、探索产品
- **价值路径**：浏览 → 兴趣 → 注册 → 转化
- **触达渠道**：官网、社媒、广告落地页

### 10. 生态伙伴 (Ecosystem Partner)
- **特征**：OPC共生体系成员
- **需求**：资源匹配、项目共创、收益共享
- **价值路径**：加入 → 匹配 → 共创 → 分成
- **触达渠道**：OPC平台、社群、活动

## 6W 分析框架
- **Who**：用户是谁？（身份识别）
- **What**：用户需要什么？（需求分析）
- **Why**：为什么需要？（动机分析）
- **When**：什么时候需要？（时机判断）
- **Where**：从哪里来？（渠道归因）
- **hoW**：如何满足？（解决方案）
