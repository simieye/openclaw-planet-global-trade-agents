# Agent 智能体配置 — Layer 5

## OpenClaw 企业 100 个 Agent 角色体系

### 6 层智能体工作层架构

```
Layer 1: Identity 身份中枢 — 企业身份定义与权限管理
Layer 2: Soul 灵魂核心 — 核心价值观与伦理框架
Layer 3: Memory 记忆系统 — 四级记忆架构
Layer 4: User 用户理解 — 10类用户识别与6W分析
Layer 5: Agent 智能体配置 — 100 Agent角色体系（本层）
Layer 6: Tools 工具系统 — 7层工具矩阵
```
