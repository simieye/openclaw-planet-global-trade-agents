# seo-geo-claude-skills（20合1套装）

## 描述
一套20个SEO+GEO技能，覆盖关键词研究→内容生产→页面优化→排名监控全链路。包含keyword-research、serp-analysis、geo-content-optimizer、schema-markup-generator等，每个可单独装。

## 分类
SEO / GEO / AI搜索优化

## 安装
```bash
npx skills add aaron-he-zhu/seo-geo-claude-skills
```

## 来源
