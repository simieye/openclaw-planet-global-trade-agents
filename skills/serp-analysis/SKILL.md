# serp-analysis

## 描述
拆解谷歌搜索结果页——精选摘要、PAA问答、AI Overview。能检测AI Overview的触发条件，告诉你怎么被AI引用。

## 分类
SEO / GEO / AI搜索优化

## 来源
https://playbooks.com/skills/openclaw/skills/serp-analysis

## 工作流
1. 输入目标关键词
2. 抓取 Google SERP 完整结果
3. 识别精选摘要（Featured Snippet）
4. 提取 PAA（People Also Ask）问答
5. 检测 AI Overview 是否触发
6. 分析 AI Overview 引用来源特征
7. 输出：排名因素分析 + AI 引用优化建议

## 触发词
SERP分析、搜索结果、精选摘要、AI Overview、谷歌排名

## 依赖
- SERP 抓取 API
