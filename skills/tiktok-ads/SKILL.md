# tiktok-ads

## 描述
分析广告数据，给出Hook优化、CTA测试、受众定向的具体建议。下载量1.3K+。

## 分类
TikTok & 短视频内容工业化

## 来源
https://clawhub.ai/skills/tiktok-ads

## 工作流
1. 连接 TikTok Ads 数据
2. 分析广告组表现（CTR/CVR/CPA）
3. Hook 优化建议（开头3秒吸引力）
4. CTA 测试方案（不同行动号召对比）
5. 受众定向调整建议
6. 输出优化报告

## 触发词
TikTok广告、广告优化、Hook、CTA、受众定向

## 依赖
- TikTok Ads API
