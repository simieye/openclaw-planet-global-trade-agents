# skill-amazon-ads-optimizer

## 描述
基于Amazon Ads API v3，全面接管SP广告。以分钟级频率提取活动摘要，ACoS偏离基准线时立即用数学模型重算竞价推回API。在竞争对手睡觉的时区里悄悄抢广告位。

## 分类
广告投放与ROI动态优化

## 来源
https://github.com/Zero2Ai-hub/skill-amazon-ads-optimizer

## 工作流
1. 连接 Amazon Ads API v3
2. 分钟级频率提取 SP 广告活动摘要
3. 实时监控 ACoS 偏离基准线
4. 偏离时自动用数学模型重算竞价
5. 通过 API 推送新竞价
6. 记录每次调整日志（可追溯）
7. 支持时区策略（竞品睡觉时自动加价）

## 触发词
亚马逊广告、ACoS优化、SP广告、竞价调整、Amazon PPC

## 依赖
- Amazon Ads API v3
- 竞价数学模型
