# perplexity-research

## 描述
用Perplexity Agent API做深度研究，支持多模型对比验证（GPT-5.2、Claude、Gemini）。出高质量行业分析报告。

## 分类
竞品监控与市场洞察

## 来源
https://playbooks.com/skills/openclaw/skills/perplexity-research

## 工作流
1. 输入研究主题
2. Perplexity Agent API 深度搜索
3. 多模型对比验证（GPT/Claude/Gemini）
4. 交叉验证信息准确性
5. 整合多源数据
6. 输出高质量行业分析报告

## 触发词
深度研究、行业报告、Perplexity、多模型验证

## 依赖
- Perplexity API
- 多模型访问
