# skill-amazon-listing-optimizer

## 描述
Listing终极手术刀。拉取ASIN指标，爬取类目Best Seller核心页面，交叉对比关键词搜索量。长尾词前置保证移动端露出，兼顾阅读流畅性。内置图像合规检查——主图违规立即移除背景通过SP-API推送，全程不到5秒。

## 分类
Listing优化与前端转化率提升

## 来源
https://github.com/Zero2Ai-hub/skill-amazon-listing-optimizer

## 工作流
1. 输入 ASIN
2. 拉取 Listing 指标（会话/转化/BSR）
3. 爬取类目 Best Seller 页面
4. 交叉对比关键词搜索量
5. 长尾词前置优化（移动端优先）
6. 图像合规检查（主图违规检测）
7. 违规时自动移除背景 → SP-API 推送（<5秒）
8. 输出优化建议 + 自动修复

## 触发词
亚马逊Listing、标题优化、五点描述、主图合规、A9算法

## 依赖
- Amazon SP-API
- Amazon Ads API
- 图像处理
