# adspirer-ads-agent

## 描述
一个Skill管四大平台——Google Ads、Meta Ads、LinkedIn Ads、TikTok Ads，100+个工具。直连API，用自然语言创建广告系列、拉实时数据、优化预算。所有新建广告默认暂停，你确认才上线。

## 分类
广告投放与ROI动态优化

## 安装
```bash
openclaw plugins install openclaw-adspirer
```

## 来源
https://playbooks.com/skills/openclaw/skills/adspirer-ads-agent

## 工作流
1. 自然语言描述广告需求
2. Agent 自动选择目标平台（Google/Meta/LinkedIn/TikTok）
3. 直连 API 创建广告系列（默认暂停状态）
4. 拉取实时数据（花费/展示/点击/转化）
5. AI 分析表现 → 预算优化建议
6. 人工确认后上线

## 触发词
广告投放、Google Ads、Meta Ads、TikTok Ads、跨平台广告

## 依赖
- Google Ads API
- Meta Ads API
- LinkedIn Ads API
- TikTok Ads API
