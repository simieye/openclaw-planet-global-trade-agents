# seo-competitor-analysis

## 描述
深度SEO竞品分析——关键词布局、外链情况、内容策略全扫描。下载量5.5K+。

## 分类
SEO / GEO / AI搜索优化

## 来源
https://clawhub.ai/skills/seo-competitor-analysis

## 工作流
1. 输入竞品域名
2. 关键词布局扫描 → 排名词/流量词/长尾词
3. 外链分析 → 数量/质量/锚文本分布
4. 内容策略分析 → 发布频率/内容类型/主题覆盖
5. 技术 SEO 对比 → 速度/结构/移动端
6. 差距分析 → 我们缺失的关键词/内容
7. 输出：竞品 SEO 报告 + 行动建议

## 触发词
SEO竞品、关键词分析、外链分析、内容策略

## 依赖
- SEO 数据 API（Ahrefs/Semrush 或替代）
