# Meta-ads-report

## 描述
在聊天里直接查Meta广告表现，实时拉取ROAS、CPA、CTR，不用登后台。

## 分类
广告投放与ROI动态优化

## 来源
https://github.com/VoltAgent/awesome-openclaw-skills

## 工作流
1. 自然语言查询（如"昨天ROAS最高的广告组"）
2. 连接 Meta Ads API
3. 拉取实时数据：ROAS/CPA/CTR/CPM/转化
4. 格式化输出（表格/图表）
5. 支持日期对比和趋势分析

## 触发词
Meta广告、ROAS、CPA、Facebook广告、广告报表

## 依赖
- Meta Ads API
