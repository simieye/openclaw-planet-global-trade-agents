# instagram-poster

## 描述
解决自动发布的最后一公里。绕过官方API限制，通过Telegram桥接把图片和Reels无损推送到Instagram主页。巧妙规避风控，降低封号风险。

## 分类
社媒矩阵自动驾驶与多平台分发

## 来源
https://github.com/VoltAgent/awesome-openclaw-skills

## 工作流
1. 准备要发布的图片/Reels
2. Telegram Bot 桥接（绕过 API 限制）
3. 无损推送到 Instagram 主页
4. 风控规避策略（随机间隔/行为模拟）
5. 发布状态确认
6. 发布日志记录

## 触发词
Instagram发布、自动发帖、Telegram桥接、IG自动发布

## 依赖
- Telegram Bot API
- Instagram 自动化工具
