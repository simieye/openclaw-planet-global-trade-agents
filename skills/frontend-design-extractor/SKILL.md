# frontend-design-extractor

## 描述
独立站视觉间谍。深度解析高转化竞品网站，提取对方经过A/B测试验证的CSS变量、按钮参数、排版层级，直接参考优化你的Shopify主题。

## 分类
Listing优化与前端转化率提升

## 来源
https://github.com/sundial-org/awesome-openclaw-skills

## 工作流
1. 输入竞品独立站 URL
2. 深度解析页面结构
3. 提取 CSS 变量（颜色/间距/字体）
4. 提取按钮参数（大小/颜色/圆角/hover效果）
5. 分析排版层级（H1-H6/段落/留白）
6. 识别 A/B 测试痕迹（变量命名/注释）
7. 输出可直接参考的 Shopify 主题优化建议

## 触发词
设计提取、CSS分析、竞品设计、Shopify主题、A/B测试

## 依赖
- 网页 CSS 解析
- Shopify 主题结构知识
