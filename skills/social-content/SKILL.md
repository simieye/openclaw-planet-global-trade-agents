# social-content

## 描述
跨平台社媒内容一站式创建——LinkedIn、Twitter/X、Instagram、TikTok、Facebook全覆盖。输入品牌调性和目标受众，自动生成各平台适配内容，支持排期日历。

## 分类
社媒矩阵自动驾驶与多平台分发

## 来源
https://playbooks.com/skills/openclaw/skills/social-content

## 工作流
1. 输入品牌调性 + 目标受众
2. 选择目标平台（LinkedIn/Twitter/Instagram/TikTok/Facebook）
3. 自动适配各平台内容格式和语气
4. 生成多版本供选择
5. 排期日历管理
6. 内容预览 + 一键发布

## 触发词
社媒内容、跨平台、LinkedIn、Twitter、排期发布

## 依赖
- 各平台 API
