# ga4-analytics

## 描述
GA4 + Search Console全套分析，支持日期对比、实时快照、URL重新索引。结果自动保存JSON并生成Markdown摘要。下载量4.6K+。

## 分类
广告投放与ROI动态优化

## 来源
https://playbooks.com/skills/openclaw/skills/ga4-analytics

## 工作流
1. 连接 GA4 + Search Console API
2. 日期对比分析（环比/同比）
3. 实时快照（当前在线/流量来源）
4. URL 重新索引请求
5. 自动生成 JSON 数据 + Markdown 摘要
6. 关键指标预警（流量骤降/转化异常）

## 触发词
GA4、Google Analytics、Search Console、流量分析、网站分析

## 依赖
- Google Analytics Data API
- Google Search Console API
