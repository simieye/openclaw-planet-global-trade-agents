# content-creator

## 描述
带品牌声音分析器和SEO优化器。先分析现有内容的调性，再结合SEO检查输出品牌一致且搜索友好的内容。

## 分类
SEO / GEO / AI搜索优化

## 来源
https://playbooks.com/skills/openclaw/skills/content-creator

## 工作流
1. 输入品牌现有内容样本
2. 品牌声音分析器 → 提取调性/语气/词汇特征
3. 输入目标关键词 + 内容主题
4. SEO 优化器 → 关键词密度/结构/可读性
5. 生成品牌一致 + SEO 友好的内容
6. 输出：完整文章 + SEO 评分

## 触发词
内容创作、品牌声音、SEO写作、内容优化

## 依赖
- SEO 分析工具
- NLP 文本分析
