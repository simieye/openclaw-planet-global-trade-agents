# claude-ads

## 描述
跨平台广告全维度审计。穿透Meta、Google、YouTube、TikTok、LinkedIn执行186项加权评分检查，识别广告疲劳和受众重叠竞价。GitHub 751 Stars，当前最强的开源营销审计工具。

## 分类
广告投放与ROI动态优化

## 来源
https://github.com/AgriciDaniel/claude-ads

## 工作流
1. 连接各平台广告账户
2. 执行 186 项加权评分检查
3. 广告疲劳检测（频次/CTR衰减/素材老化）
4. 受众重叠分析（跨平台重复竞价检测）
5. 预算分配效率评估
6. 每个维度打分 + 权重汇总
7. 输出审计报告 + 优先级修复清单

## 触发词
广告审计、广告疲劳、受众重叠、186项检查、跨平台审计

## 依赖
- 多平台 Ads API
- Claude API（分析引擎）
