# google-analytics

## 描述
Google Analytics API集成，管理账户、属性、数据流，跑自定义报告。下载量6.4K+。

## 分类
广告投放与ROI动态优化

## 来源
https://playbooks.com/skills/openclaw/skills/google-analytics

## 工作流
1. 连接 Google Analytics Admin API
2. 管理账户/属性/数据流
3. 创建自定义报告
4. 维度/指标灵活组合
5. 定时报告 + 异常预警
6. 数据导出（JSON/CSV）

## 触发词
Google Analytics、GA管理、自定义报告、数据分析
