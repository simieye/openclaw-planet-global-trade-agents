# Windsor-ai

## 描述
一个接口连325+数据源——Facebook Ads、GA4、HubSpot、Google Ads。问一句话就拿到跨平台汇总数据，彻底打破孤岛。

## 分类
广告投放与ROI动态优化

## 来源
https://github.com/VoltAgent/awesome-openclaw-skills

## 工作流
1. 连接 Windsor.ai 统一 API
2. 自然语言查询跨平台数据
3. 自动路由到对应数据源（325+）
4. 数据汇总/去重/归因
5. 输出统一报表（跨平台 ROI 对比）

## 触发词
跨平台数据、数据汇总、Windsor、统一报表、数据孤岛

## 依赖
- Windsor.ai API
